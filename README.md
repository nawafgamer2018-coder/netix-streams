Netix is a fast, lightweight, and modern streaming web application designed to browse and play movies and TV shows effortlessly. Built with a Netflix-style UI, it integrates directly with the TMDB API for rich metadata, trending lists, and high-quality posters, backed by an automated multi-provider video player.

✨ Key Features
TMDB Metadata Integration: Real-time data for trending movies, TV series, search results, and category rows.

Automated Embed Player: Dynamic fallback logic powered by Videasy to auto-play media using TMDB IDs without manual configuration.

Custom Source Overrides: Save, edit, or remove custom stream links, MP4 URLs, or iframe embeds on a per-title basis via browser localStorage.

Sleek & Responsive UI: Fully responsive 16:9 media slots, custom dark-mode styling, and smooth layout components.

Zero Configuration: Pre-configured TMDB API key fallback for immediate local or hosted deployment.

🛠️ Tech Stack
Frontend: React, Vite, TypeScript

Styling: Tailwind CSS, shadcn/ui

Routing & Data: TanStack Router, TanStack Query

Icons & Notifications: Lucide React, Sonner
